# Security Policy

## Reporting Security Vulnerabilities

Fixer processes all user files and photos strictly client-side inside the local web browser memory sandbox. No files are ever transmitted to any external server.

If you discover a security vulnerability, privacy leak, or sandbox bypass within Fixer, please report it directly:

- **Maintainer**: JOJIN JOHN
- **LinkedIn**: [https://www.linkedin.com/in/jojin-john/](https://www.linkedin.com/in/jojin-john/)
- **GitHub**: [https://github.com/jojin1709/fixer/issues](https://github.com/jojin1709/fixer/issues)

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Affected browser(s) and operating system(s).

We appreciate responsible disclosure and will investigate and patch security issues promptly.
