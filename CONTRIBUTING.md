# Contributing to Fixer

Thank you for your interest in Fixer!

## How You Can Contribute

1. **Bug Reports & Feature Suggestions**:
   - Please open an issue on the [GitHub Issues tracker](https://github.com/jojin1709/fixer/issues).
   - Describe the unexpected behavior clearly and provide sample images or browser details if applicable.

2. **Pull Requests**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/awesome-feature`).
   - Keep pull requests focused, clean, and adhering to vanilla HTML/CSS/JS without unneeded build bloat.
   - Commit your changes and open a Pull Request for review by **JOJIN JOHN**.
